## 设计哲学（源自大摩疫情稳定性框架的移植）

把"社会稳定性"这个模糊大概念拆成五个**彼此正交、各自可观测、带先行性**的维度，
每个维度独立评分再加权合成。关键有两条：
1. 分项之间正交（不重叠，避免同一风险被重复计数）。
2. 盯每个分项里"会先动的东西"（先行指标），而非崩溃时才动的滞后指标。

## 五支柱是一条因果链，不是并列清单

```
制度(规则) → 财政+货币(钱) → 社会+强制机构(人) → 外部冲击推过临界
    三          一 + 二              四 + 五
```

1998 崩溃就是这条链走完的样本：关联贷款(制度)→企业外债失控(财政)→卢比崩溃(货币)
→中产上街(社会)→军内分裂(强制机构)→崩溃。

## 评分刻度

- 0–100 分，**越高越稳**。
- 映射 1–5 级预警：≥70 绿·稳定 / ≥55 黄绿·平稳 / ≥45 橙黄·承压 / ≥30 橙红·预警 / <30 红·危机。

## 合成规则（可复现）

```
支柱分 = Σ(子因子分 × 子因子权重) + 定性调整量(pillarAdj)
综合指数 = Σ(支柱分 × 支柱权重)
```

- 每个支柱内子因子权重之和 = 1。
- `pillarAdj` 是明确标注的定性微调，必须写理由（硬阈值未捕捉的因素）。
- 权重预设：全景均衡(各20%) / 投资敞口(财政28/货币28/制度18/社会13/强制13) /
  合规牌照(财政13/货币15/制度32/社会12/强制28)。

## 混合计量：两类子因子

### type=quant（硬数据项 · 阈值公式）
用真实实测值套阈值档，可复现。例：
- 主权风险溢价 = 10年期国债收益率。≤6%=75 / 6–6.8=55 / 6.8–7.3=48 / >7.3=25。
  当前 7.14% → 48 分。
- 外部流动性缓冲 = 外储进口覆盖月数。≥6=80 / 4.5–6=60 / 3–4.5=40 / <3=15。
  当前 5.6 → ~62 分。
- 制造业动能 = PMI。≥52=70 / 50–52=55 / 48–50=45 / <48=30。当前 46.9 → 35 分。
- 消费者信心 = CCI。≥125=70 / 120–125=58 / 115–120=50 / <115=35。当前 117.8 → 50 分。

### type=ordinal（制度项 · 5 档序数标尺）
无法用硬数据，用 0/25/50/75/100 五档定性锚定，透明但含判断。例：
- 央行独立性：100=法定独立+人事专业 / 75=独立但政治任命 / 50=独立受立法挑战 /
  25=人事政治化+目标被修订 / 0=从属财政。当前落 25（侄子进 BI + P2SK 改目标）。

## 事实/判断分离（4 类来源标签）

每条依据标注：【事实】公开数据文件 / 【引述】官方机构原话 / 【判断】结构化分析 /
【待补】可接实时数据。界面上分"硬数据区◆"和"判断区◇"两块呈现。

## 1998 锚定

每个支柱标注其 1998 位置，用于历史类比对照。锚定推理见各支柱 `hist1998Reason`。
最关键：制度支柱 1998=45，当前=34——当前更低，因为 1998 前被俘获的是监管执行层，
央行/技术官僚体系仍运转；今天被侵蚀的是央行独立性本身这个更上游的锚。

## 诚实边界

本框架**非实时数据终端**。硬数据来自公开源（标注日期），判断项为结构化分析。
真正的自动刷新需接后端生成 `data/dashboard-data.json`（见 CLAUDE.md 待办）。
评分可被专业使用者挑战——这是特性，不是缺陷。
