## 设计哲学（源自大摩疫情稳定性框架的移植）

把"社会稳定性"这个模糊大概念拆成五个**彼此正交、各自可观测、带先行性**的维度，
每个维度独立评分再加权合成。关键有两条：
1. 分项之间正交（不重叠，避免同一风险被重复计数）。
2. 盯每个分项里"会先动的东西"（先行指标），而非崩溃时才动的滞后指标。

## 五支柱是一条因果链，不是并列清单

```
制度(规则) → 财政+货币(钱) → 社会+强制机构(人) → 外部冲击推过临界
    三          一 + 二              四 + 五
```

1998 崩溃就是这条链走完的样本：关联贷款(制度)→企业外债失控(财政)→卢比崩溃(货币)
→中产上街(社会)→军内分裂(强制机构)→崩溃。

## 评分刻度

- 0–100 分，**越高越稳**。
- 映射 1–5 级预警：≥70 绿·稳定 / ≥55 黄绿·平稳 / ≥45 橙黄·承压 / ≥30 橙红·预警 / <30 红·危机。

## 合成规则（可复现）

```
支柱分 = Σ(子因子分 × 子因子权重) + 定性调整量(pillarAdj)
综合指数 = Σ(支柱分 × 支柱权重)
```

- 每个支柱内子因子权重之和 = 1。
- `pillarAdj` 是明确标注的定性微调，必须写理由（硬阈值未捕捉的因素）。
- 权重预设：全景均衡(各20%) / 投资敞口(财政28/货币28/制度18/社会13/强制13) /
  合规牌照(财政13/货币15/制度32/社会12/强制28)。

## 混合计量：两类子因子

### type=quant（硬数据项 · 阈值公式）
用真实实测值套阈值档，可复现。例：
- 主权风险溢价 = 10年期国债收益率。≤6%=75 / 6–6.8=55 / 6.8–7.3=48 / >7.3=25。
  当前 7.14% → 48 分。
- 外部流动性缓冲 = 外储进口覆盖月数。≥6=80 / 4.5–6=60 / 3–4.5=40 / <3=15。
  当前 5.6 → ~62 分。
- 制造业动能 = PMI。≥52=70 / 50–52=55 / 48–50=45 / <48=30。当前 46.9 → 35 分。
- 消费者信心 = CCI。≥125=70 / 120–125=58 / 115–120=50 / <115=35。当前 117.8 → 50 分。

### type=ordinal（制度项 · 5 档序数标尺）
无法用硬数据，用 0/25/50/75/100 五档定性锚定，透明但含判断。例：
- 央行独立性：100=法定独立+人事专业 / 75=独立但政治任命 / 50=独立受立法挑战 /
  25=人事政治化+目标被修订 / 0=从属财政。当前落 25（侄子进 BI + P2SK 改目标）。

## 市场层：相对同侪、偏离一年均值（2026-10-16 起）

**起因**：2026-10-15 MSCI 发起咨询，拟将印尼由新兴市场降为 Standalone；旧口径下当周货币支柱
一分未动（47→47）。诊断出三个结构性毛病：

1. **受起点基数支配。** 股市与汇率按「年内」计，上年末是唯一参照——1–4 月的暴跌一直记到
   12 月 31 日，1 月 1 日清零。换成滚动窗口也不行：同一天印尼对新兴市场滚动 6 个月 −30%、
   滚动 3 个月 −4%（9 月甚至 +16%），因为 3 个月前已是坑底。换窗口只是换了一个起点。
2. **分不清本国恶化与全球同跌。** 全球一起跌 20%，旧口径照扣。
3. **制度处置与价格反应混在一起**，且制度那一半只占 0.06。

**新口径**（`scripts/market_relative.py`，读数存档 `data/market-relative/YYYY-MM-DD.json`）：

| driver | 读数 | 映射 | 数据 |
|---|---|---|---|
| 股市相对表现(对MSCI EM) · 货币 0.20 | MSCI Indonesia ÷ MSCI EM 偏离其 250 日均值 | clamp(55 + 偏离%, 5, 75) | MSCI 官方指数 105767 / 891800（USD） |
| 汇率相对强弱(对亚洲五币) · 货币 0.25 | 每美元卢比 ÷ THB/MYR/PHP/INR/KRW 几何均值，偏离 250 日均值（正=卢比相对走弱） | clamp(55 − 5×偏离%, 5, 75) | ECB 欧元参考汇率经 USD 交叉 |
| 资本市场治理与国际准入 · 制度 0.15 | MSCI/FTSE 等对印尼市场准入的处置状态 | 序数 70/45/30/20/10/0 | 指数提供方公告原文 |

- **没有日历起点**：参照是滚动一年均值，伤害随时间平滑淡出。
- **全球同跌不扣分**：分子分母同跌，比值不动（`test_market_relative.py` 固化）。
- **连续映射**：去掉档界悬崖（旧档界让 17,948 与 17,951 差 17 分）与尾部底档（<−30% 一档到底）。
  偏离先按一位小数取整再十进制半数进位——看板上写的数字就能复算出分。
- **截点**：期次前一自然日及之前最近的收盘，历史重算也按此执行，不设逐期例外。
- **数据不足拒绝出数**：窗口 < 240 个观测、或任一币种当日缺定盘，不出数、不补零。

**准入为什么迁到制度支柱、为什么 0.15、权重从哪来**：MSCI/FTSE 的判断针对的是市场治理
（股权透明度、交易监控、执法），本质是制度问题；降级在咨询—决定—执行的一年多里是持续状态，
通过被动资金、汇率与融资成本持续传导，不是一次性事件。0.15 由制度其余五项**等比例 ×0.85**
腾出——不从单项挖：从高分项（国际治理 42）挖，支柱会在 MSCI 什么都没发生时先掉 0.5；
从底档项（政策方差 30）挖，会让最差的信号算得更轻。等比例缩放的机械漂移为 0，支柱变动可以
完整归因到准入这一项。

**它不负责什么**：绝对压力（例如全亚洲一起崩、美元债偿付变重）属财政与外部脆弱性支柱；
JISDOR 与 18,000 心理位保留在证据里作参照，不再定档。

**历史**：07-22 起各期全部重算（07-22…08-11 的 driver 取自 git 历史中当期 data.js，08-20 起取自
driver 快照），综合下移 0.4–1.6 分，走势形状基本不变；07-07/07-16 无 driver 级记录，标
`fxBasis: "legacy"` 保留。准入在 08-20 之前未测量，按惯例权重退回、制度支柱不动。

## 诚实边界

本框架**非实时数据终端**。硬数据来自公开源（标注日期），判断项为结构化分析。
真正的自动刷新需接后端生成 `data/dashboard-data.json`（见 CLAUDE.md 待办）。
评分可被专业使用者挑战——这是特性，不是缺陷。
